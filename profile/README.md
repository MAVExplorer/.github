## Обзор проекта

**MAVExplorer** — инструмент анализа полётных данных из экосистемы **ArduPilot**, предназначенный для исследования журналов автопилота и диагностики поведения беспилотного аппарата. Программа входит в набор инструментов MAVProxy и позволяет открывать логи, просматривать записанные сообщения и строить графики различных параметров полёта.

Основное назначение MAVExplorer — детальный разбор данных после выполнения полёта или наземного тестирования. Вместо просмотра только основных показателей пользователь получает доступ к большому количеству сообщений, записанных автопилотом: состоянию датчиков, GPS, ориентации аппарата, работе EKF, управляющим сигналам, параметрам питания и другим данным.

Инструмент особенно полезен при поиске причин вибраций, проблем навигации, нестабильного поведения аппарата или других событий, которые сложно определить непосредственно во время полёта.

## Анализ логов ArduPilot

После полёта автопилот **ArduPilot** может сохранять подробный DataFlash-журнал. В нём содержится временная последовательность сообщений, описывающих состояние аппарата и работу его компонентов.

MAVExplorer позволяет открыть такой лог и исследовать интересующий участок полёта. Например, при появлении нестабильности можно сопоставить данные IMU, ориентацию аппарата, управляющие выходы и изменения режима полёта.

Для навигационных проблем можно изучать GPS и данные системы оценки положения. При диагностике питания полезно сравнивать напряжение, ток и другие доступные параметры с моментами изменения нагрузки.

## Графики и диагностика

| Данные | Что можно исследовать |
|---|---|
| **ATT** | Ориентацию и движение аппарата |
| **IMU** | Акселерометры и гироскопы |
| **GPS** | Координаты, скорость и качество навигационных данных |
| **BAT** | Записанные показатели системы питания |
| **RCIN** | Входные команды радиоуправления |
| **RCOU** | Управляющие выходы автопилота |
| **MODE** | Изменения режимов полёта |
| **EKF** | Работу алгоритмов оценки состояния |
| **VIBE** | Записанные показатели вибрации |
| **BARO** | Данные барометрических датчиков |

Точный набор сообщений зависит от версии **ArduPilot**, конфигурации логирования, типа аппарата и подключённого оборудования. Поэтому в разных логах доступный набор графиков и параметров может отличаться.

Возможность строить собственные выражения делает MAVExplorer полезным не только для обычного просмотра журнала, но и для более глубокого технического анализа.

## MAVExplorer, MAVProxy и pymavlink

MAVExplorer относится к инструментам экосистемы **MAVProxy / pymavlink** и ориентирован на пользователей, которым требуется подробный доступ к данным ArduPilot.

Вместе эти инструменты формируют удобный набор для разработки и диагностики UAV. MAVProxy может использоваться для работы с MAVLink-соединениями и телеметрией, а MAVExplorer — для последующего исследования записанных полётных данных.

Такой подход особенно полезен при разработке собственных аппаратов, тестировании новых конфигураций, настройке автопилота и поиске причин необычного поведения UAV.

## Быстрый старт

1. Получите полётный лог с совместимого автопилота **ArduPilot**.
2. Запустите **MAVExplorer**.
3. Откройте необходимый файл журнала.
4. Проверьте доступные типы сообщений.
5. Выберите интересующие параметры.
6. Постройте графики для нужного участка полёта.
7. Сопоставьте данные GPS, IMU, EKF, RC и других подсистем.
8. Проверьте моменты переключения режимов и появления ошибок.
9. При необходимости используйте собственные выражения для анализа.
10. Сохраняйте исходный лог без изменений для повторной диагностики.
